# TrainBoard 使用指南

## 安装与启动

Python 3.10 或更新版本，依赖见根目录 requirements.txt。安装后复制 panel.example.json 为 panel.json，在同目录运行 `python -m trainboard`。

启动参数包括 `--config path/to/panel.json`、`--port 8766`、`--host 127.0.0.1` 和 `--no-browser`。配置文件的位置决定相对路径基准，切换工作目录不会改变已配置路径的含义。

## 配置字段

| 字段 | 含义 |
|---|---|
| title | 网页标题 |
| runs_dir | 指标与历史运行根目录 |
| state_dir | 队列 JSON 和标准输出日志目录 |
| primary_metric | 概览用于比较的指标，例如 auc、accuracy、valid_loss |
| metric_mode | max 为越大越好，min 为越小越好 |
| min_available_gib | 可选的派发前可用物理内存检查，默认 0 关闭 |
| entries | 训练入口字典，键使用英文字母、数字、下划线或连字符 |

每个入口指定 script、cwd、可选 python、固定 args、env 和 parameters。args 必须是字符串数组。参数通过独立 argv 元素传递，空格路径可正常使用。脚本不会经 shell 解释。

args 和 env 支持 `{run_dir}`、`{runs_dir}`、`{job_id}` 占位符。每次任务还会收到 `TRAINBOARD_RUN_DIR`、`TRAINBOARD_JOB_ID` 环境变量。训练脚本应把指标与输出存放在分配的运行目录，以便队列和曲线对应。

parameters 支持 int、float、str。可设置 label、flag、default、min、max、choices。面板按配置生成参数表单，空值沿用配置默认值。需要布尔开关时，可通过固定 args 或字符串枚举接入训练脚本的参数形式。

## 队列与进程生命周期

加入任务后点击开始。上移、下移和移除仅作用于等待中的任务。暂停派发让当前任务继续，停止按钮终止当前任务及其子进程，并暂停后续派发。任务失败同样暂停队列，用户检查日志后手动开始。

关闭浏览器后服务与训练继续。退出服务时等待正在运行的任务自然完成，再释放队列锁。服务意外退出后，运行任务显示「已中断」，启动派发前会检查原 PID 和进程创建时间，避免重叠启动。

队列恢复保留原参数；修改配置删除了某个入口后，旧任务无法启动会显示失败，请重新添加有效入口。训练中不应手工编辑 queue.json。

同一 state_dir 仅允许一个服务进程。不同 state_dir 的实例互不协调，使用者需要安排 GPU 和内存资源，避免外部训练争用。

## 历史结果与动态曲线

runs_dir 下可放多级运行文件夹，最大扫描深度为 5。每个运行可提供 metrics.jsonl、history.csv 或 epoch_metrics.csv。推荐按轮写一行并及时 flush，浏览器约每 2.2 秒刷新，历史列表约每 4 秒刷新。

可同时记录 accuracy、auc、f1、train_loss、valid_loss、lr 等任意数值字段。指标选择器可以切换字段；损失标签展示训练和验证损失。宏指标的别名自动转换，macro_auc → auc、macro_f1 → f1、val_loss → valid_loss。

可选 `per_class.csv` 使用 `name,auc` 表头。预先生成的 training_curves.png、per_class_auc.png、roc_pr.png、confusion_matrices.png、confusion_matrix.png 可以从结果区下载。

面板如实展示训练程序提供的指标。验证集独立性、训练内评估和交叉验证定义由训练程序负责，并应写在该实验的说明中。

## 共享访问

服务每次启动生成不同的管理员密钥和只读密钥，完整访问链接会打印在终端。URL 中的 fragment 由浏览器读取，后续 API 使用 X-Panel-Token 请求头。浏览器地址栏会移除 fragment，密钥保存在当前 tab 的 sessionStorage。

只读链接可查看队列、指标、日志和图，服务端拒绝该密钥的所有写操作和源码预览。日志可能包含训练命令和本地路径，应仅分享给受信任的合作者。

如需固定密钥，启动前设置环境变量 TRAINBOARD_ADMIN_TOKEN 和 TRAINBOARD_VIEW_TOKEN。它们必须不同且长度至少 16 个字符。不要写进版本库。反向代理应透传 Host，必要时重写 Origin 与 Host 保持一致。

## 常见问题

打不开页面时检查端口是否被占用，或者用 --port 切换。访问密钥错误时重新打开本次启动输出的完整链接。

没有曲线时确认训练写到了分配的 run_dir，且指标包含 epoch 及至少一个数值字段。控制台进度行与指标文件是两条独立通道，都需要训练脚本主动输出。

Conda 环境接入时，填该环境 python 的完整路径。面板自身只需 psutil，训练依赖需在对应环境独立安装。

暂不提供一键恢复已终止任务。保存检查点与恢复参数由训练脚本实现，再通过配置新增恢复入口或参数。
